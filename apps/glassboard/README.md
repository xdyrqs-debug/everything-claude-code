# Glassboard

Локальное десктоп-приложение для структурирования задач в стиле стеклянных виджетов Apple.
Работает без интернета. Данные каждого пользователя зашифрованы его паролем.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| **Вход** | Пароль задаёт сам пользователь при добавлении в приложение. Можно завести несколько пользователей. Неверный пароль — встряхивание карточки и растущая задержка после 3 ошибок. Автоблокировка при бездействии, сне или блокировке экрана, `Ctrl/⌘+L` — заблокировать вручную. |
| **Задачи** | Проекты, «Сегодня», «Со сроком»; канбан (перетаскивание между колонками и внутри колонки) и список с группировкой по срокам; подзадачи с прогрессом, приоритеты, сроки, теги, описание. Быстрый ввод: `Отчёт !3 #работа @завтра` (`!1–3` приоритет, `#тег`, `@сегодня`, `@завтра`, `@неделя`, `@25.12`, `@2026-12-25`). |
| **Записки** | Каждая записка — отдельное стеклянное окно на рабочем столе. 📌 закрепляет её поверх всех окон. У каждой свой цвет и прозрачность. Заголовки H1/H2/H3, жирный/курсив, чек-листы. Положение и размер запоминаются, открытые записки возвращаются после перезапуска. Задачу, стикер с доски или ветку mind map можно одной командой «вынести на экран». |
| **Доска** (как Miro) | Бесконечный холст с сеткой, масштаб колесом с `Ctrl/⌘` или жестом, перемещение пробелом/средней кнопкой/рукой. Стикеры, текст, прямоугольники, эллипсы, фреймы (двигают вложенные объекты), стрелки между объектами с подписями, перо, карточки задач, которые обновляются вместе с задачей. Выделение рамкой и с Shift, изменение размера, цвет, слои, дублирование, копировать/вставить, отмена/повтор. «Превратить в задачу» прямо из стикера. Несколько досок. |
| **Mind map** | Центральная тема с ветками, раскладка по обе стороны, цвет ветки, сворачивание, перетаскивание узла на другой для переноса, навигация стрелками. `Tab` — дочерний, `Enter` — соседний, `F2`/начать печатать — правка, `Space` — свернуть. «☑ В задачи» превращает ветку в задачу с подзадачами. Несколько карт. |
| **Вместе** | Совместные проекты в реальном времени: общие задачи, доска с живыми курсорами участников и чат. Партнёр заходит по ссылке-приглашению, история чата сохраняется у каждого участника. Подробности ниже. |
| **Claude (MCP)** | Встроенный MCP-сервер: Claude Desktop или Claude Code видят ваши задачи, записки, mind map и доски и могут их менять. Всё, что делает Claude, сразу появляется в приложении. Подробности ниже. |
| **Настройки** | Светлая / тёмная / системная тема, цвет окна, цвет акцента, прозрачность окна, плотность панелей, сила размытия, фон «Аврора» или прозрачный, системное размытие (macOS vibrancy / Windows 11 Acrylic). Шрифт, размер и насыщенность отдельно для H1, H2, H3 и текста (готовые наборы или любой установленный шрифт). Цвет и прозрачность новых записок. Смена пароля, экспорт/импорт JSON, удаление профиля. |

## Запуск

Нужен [Node.js](https://nodejs.org) 20+.

```bash
cd apps/glassboard
npm install
npm start
```

Собрать установщик для своей ОС (`.dmg`, `.exe` или `.AppImage` в папке `dist/`):

```bash
npm run dist
```

Тесты шифрования и хранилища:

```bash
npm test
```

## Совместные проекты

**Создать проект.** Откройте раздел **Вместе** (`Ctrl/⌘+5`) и нажмите **Создать совместный проект**. Ссылка-приглашение вида `glassboard://join/…` сразу скопируется. Отправьте её партнёру любым мессенджером. Получить ссылку ещё раз можно кнопкой **🔗 Пригласить**.

**Присоединиться.** Партнёр открывает ссылку, и Glassboard запускается сам. Ещё один вариант — **Вместе → Присоединиться по ссылке** и вставить ссылку туда. У партнёра должен быть установлен Glassboard и создан свой профиль.

**Что становится общим:**
- Задачи проекта. Остальные ваши проекты, записки и mind map остаются личными.
- Доска проекта. На ней видны курсоры участников с именами, а у кнопки 💬 открывается чат.
- Чат. История хранится у каждого участника в его зашифрованном профиле. Кто подключился позже, получает всю переписку. После перезапуска приложения история на месте.

Изменения видны всем сразу. Если правки сделаны без связи, они сольются при переподключении. При одновременных правках одного объекта побеждает более поздняя.

**Шифрование.** Всё, что передаётся, шифруется AES-256-GCM ключом из ссылки-приглашения. Сервер связи видит только номер комнаты и зашифрованные данные. Делитесь ссылкой только с теми, кого хотите пригласить.

### Сервер связи

Участники обмениваются данными через небольшой сервер связи (relay).

- **«Этот компьютер»** (по умолчанию). Сервер запускается внутри Glassboard у создателя проекта на порту `47900`. Партнёр в той же сети (Wi-Fi или офис) подключается сразу. При первом запуске система может спросить разрешение на входящие подключения — разрешите. Пока создатель не в сети, остальные участники друг друга не видят.
- **Через интернет без своего сервера.** Откройте туннель к своему компьютеру, например бесплатным [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/):
  ```bash
  cloudflared tunnel --url http://localhost:47900
  ```
  Затем создайте проект с вариантом **«Свой сервер»** и адресом `wss://<выданный-адрес>.trycloudflare.com`.
- **Свой сервер.** Сервер связи — это один файл без зависимостей, `src/coop/relay.js`:
  ```bash
  PORT=47900 node src/coop/relay.js
  # или
  docker build -f relay.Dockerfile -t glassboard-relay . && docker run -p 47900:47900 glassboard-relay
  ```
  Поставьте его за HTTPS (Caddy, nginx, любой PaaS) и указывайте `wss://ваш-домен` при создании проекта. Такой сервер работает всегда, даже когда создатель проекта не в сети.

## Подключение Claude через MCP

Включите **Настройки → Подключение Claude (MCP) → Разрешить подключение**. Приложение покажет готовый конфиг и команду со своими путями и токеном. Скопируйте их кнопками.

**Claude Desktop.** Откройте Claude → Settings → Developer → Edit Config, вставьте блок `glassboard` в `mcpServers` файла `claude_desktop_config.json` и перезапустите Claude. Блок выглядит так:

```json
{
  "mcpServers": {
    "glassboard": {
      "command": "<путь к приложению Glassboard>",
      "args": ["<папка данных>/mcp-bridge.js", "<папка данных>/mcp.json"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}
```

Мост запускается самим приложением Glassboard в режиме Node.js, поэтому отдельно ставить Node.js не нужно. Если Node.js установлен, вместо пути к приложению можно указать `"command": "node"` и убрать `env`.

**Claude Code.** Выполните команду из настроек:

```bash
claude mcp add --transport http glassboard http://127.0.0.1:47821/mcp --header "Authorization: Bearer <токен>"
```

**Что умеет Claude:** `glassboard_overview`, `list_tasks`, `get_task`, `create_task`, `update_task` (статусы, подзадачи, сроки, теги, проект), `delete_task`, `create_project`, `list_notes`, `create_note`, `update_note` (в том числе закрепить поверх окон или убрать с экрана), `delete_note`, `list_mindmaps`, `get_mindmap`, `create_mindmap`, `add_mindmap_nodes`, `list_boards`, `add_board_items` (стикеры, фигуры, фреймы, стрелки).

Примеры запросов: «Что у меня на сегодня?», «Разбей проект „Ремонт“ на задачи со сроками», «Сделай mind map по идеям для отпуска», «Закрепи на экране чек-лист на сегодня», «Разложи эти идеи стикерами на доске и соедини стрелками».

**Безопасность:**
- Сервер слушает только `127.0.0.1`, требует токен и отклоняет запросы из браузера (заголовки `Origin` и `Host`).
- Данные доступны, только пока приложение разблокировано. После блокировки Claude получает отказ.
- Переключатель «Разрешить изменения» оставляет Claude доступ только на чтение.
- Кнопка «Сменить токен» отключает все ранее подключённые клиенты.
- Токен хранится в `mcp.json` в папке данных с правами только для владельца.

## Как хранятся данные

- Папка данных: macOS `~/Library/Application Support/Glassboard`, Windows `%APPDATA%\Glassboard`, Linux `~/.config/Glassboard`.
- `profiles/profiles.json` — только имена и цвета профилей.
- `profiles/<id>.vault` — все задачи, доски, карты и записки. Зашифрованы AES-256-GCM ключом,
  полученным из пароля через scrypt (N=2¹⁵). Сам пароль и его хэш нигде не хранятся:
  неверный пароль просто не проходит проверку подлинности шифра.
- `appearance.json` — тема и цвета для экрана входа (ничего секретного).

> Пароль восстановить нельзя. Если забудете его, данные профиля не открыть.
> Для резервной копии используйте «Настройки → Данные → Экспорт» (файл не шифруется, храните его надёжно).

## Про «стекло» на разных системах

- **macOS** — нативный vibrancy размывает рабочий стол за окном и записками.
- **Windows 11** — эффект Acrylic. На Windows 10 используется полупрозрачный фон без системного размытия.
- **Linux** — окна прозрачные, если композитор поддерживает прозрачность. Системного размытия нет,
  поэтому по умолчанию включён фон «Аврора»: цветные пятна под стеклянными панелями.

Прозрачность окна, плотность панелей и размытие настраиваются ползунками.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl/⌘ 1…6` | Задачи / Доска / Mind map / Записки / Вместе / Настройки |
| `Ctrl/⌘ N` | Новая задача (в задачах) или записка (в записках) |
| `Ctrl/⌘ L` | Заблокировать |
| `V H N T R O F C P K` | Инструменты доски: выбор, рука, стикер, текст, прямоугольник, эллипс, фрейм, стрелка, перо, задача |
| `Ctrl/⌘ Z`, `Ctrl/⌘ Shift Z` | Отменить / повторить (доска и mind map) |
| `Ctrl/⌘ D`, `Ctrl/⌘ C/V`, `Del` | Дублировать, копировать/вставить, удалить |
| `Shift 1` | Показать всё |
| `Ctrl+Alt+1/2/3`, `Ctrl+Alt+0` | Заголовок H1/H2/H3 или обычный текст в записке |
| `Ctrl+Enter` | Пункт чек-листа в записке |

## Структура

```
src/
  main/main.js        окна, записки поверх экрана, IPC, автоблокировка
  main/vault.js       шифрование профилей (scrypt + AES-256-GCM)
  main/defaults.js    стартовые данные и миграции
  main/mcp.js         MCP-сервер: инструменты для Claude, HTTP-транспорт
  main/coop.js        совместные проекты: синхронизация, чат, курсоры
  coop/relay.js       сервер связи (WebSocket без зависимостей)
  mcp/bridge.js       stdio-мост для Claude Desktop
  preload.js          безопасный мост renderer ↔ main
  renderer/
    index.html        главное окно
    note.html         окно записки
    css/              стеклянная дизайн-система
    js/core.js        хранилище, темы, undo, панорама/масштаб
    js/views/         экраны: вход, задачи, доска, mind map, записки, настройки
test/                 тесты хранилища, MCP и совместной работы
```

## Готовые сборки

GitHub Actions (`.github/workflows/glassboard-build.yml`) собирает приложение под macOS (`.dmg`),
Windows (установщик `Glassboard Setup.exe` и `.zip`) и Linux (`.AppImage`) при каждом изменении в `apps/glassboard`.
Файлы лежат на вкладке **Actions → Glassboard build → Artifacts**. Запустить сборку вручную — кнопка **Run workflow**.

Сборки не подписаны сертификатом разработчика:
- **macOS**: при первом запуске нажмите на приложение правой кнопкой → «Открыть» → «Открыть».
- **Windows**: SmartScreen → «Подробнее» → «Выполнить в любом случае».
- **Linux**: `chmod +x Glassboard-*.AppImage && ./Glassboard-*.AppImage`.
